# GymChatBot

A rule-based fitness chatbot built with Python and NLTK.

## Features

- Workout recommendations
- Beginner, intermediate, and advanced workout plans
- BMI calculator
- Protein intake calculator
- Greeting and exit handling
- Misspelling correction using fuzzy matching

## Technologies Used

- Python
- NLTK
- difflib
